# Инженерное образование 4.0

Предпубликационный сайт монографии Алексея Михайловича Давыдова. На публичной версии доступны проверяемый каталог источников, редакционный XLSX и сведения об авторе. Полный текст, PDF и факсимиле откроются после выхода финальной редакции.

Сайт: <https://adavydov.github.io/edu40-monograph/>

## Текущий публичный состав

- 160 библиографических позиций, сведённых к 154 каноническим работам;
- 13 дополнительных источников;
- 126 исследовательских материалов и отдельный каталог 21 проверяемого тезиса;
- 98 атомарных связей «тезис — доказательство» с локаторами и статусами проверки;
- 20 содержательных DATA-блоков из шести листов XLSX, представленных как проверяемые веб-таблицы;
- русская, английская и китайская навигация;
- редакционный XLSX для скачивания;
- расширенная научная биография автора с проверенными профилями и работами;
- отдельная страница для ИИ-агентов, `llms.txt`, JSON-LD и канонические правила цитирования корпуса.

## Локальная разработка

Требуется Node.js 24+.

```bash
npm ci
npm run check
npm run dev
```

Для локальной сборки с тем же базовым путём и режимом, что и на GitHub Pages:

```bash
NEXT_PUBLIC_BASE_PATH=/edu40-monograph NEXT_PUBLIC_PUBLICATION_MODE=sources-only npm run build
```

## Режим публикации

Режим по умолчанию — `sources-only`: в экспорт входят главные страницы, библиография, каталоги материалов и тезисов, матрица прослеживаемости, раздел автора и XLSX. Маршруты монографии, PDF и факсимиле автоматически исключаются из `out/`.

После получения финального PDF весь сайт восстанавливается одним флагом:

```bash
NEXT_PUBLIC_BASE_PATH=/edu40-monograph NEXT_PUBLIC_PUBLICATION_MODE=full npm run build
```

## Воспроизводимость

- `scripts/generate_monograph_assets.py` создаёт постраничные факсимиле и манифест монографии.
- `scripts/generate_catalog.mjs` строит нормализованный каталог из редакционного XLSX.
- `scripts/generate_workbook_materials.mjs` дословно извлекает 20 содержательных DATA-блоков для веб-представления.
- `scripts/validate-content.mjs` проверяет хэши, полноту страниц, связи каталога и ключевые редакционные исправления.
