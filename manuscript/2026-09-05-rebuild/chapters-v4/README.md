# Новый корпус «Права на решение»

Главы пишутся последовательно по [авторскому содержанию 4.0](../contents-v4.0.md): шесть частей, восемнадцать глав. [Пролог v1.0](../prologue-v1.0.md) сохраняет авторский текст. PRINCIPLES-01 1.0, STYLE-01 3.0 и LITERARY-WORKFLOW-01 1.0 определяют литературную работу.

Читательские исходники — chapter-01.md … chapter-18.md. В редакционных записях фиксируются вопрос, новый вклад, композиция, влияние исторического чтения, существенные возражения и конкретные исправления. Частная книжная память остаётся за пределами репозитория. Эти записи описывают текст, а не операционные обязательства.
