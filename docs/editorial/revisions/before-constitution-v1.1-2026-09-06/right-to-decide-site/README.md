# Право на решение

**Как остаться авторами будущего рядом с более сильным интеллектом**

Рабочий репозиторий футурологического манифеста-проекта: авторские тексты, редакция и сайт для чтения.

[Сайт](https://adavydov.github.io/right-to-decide/) · [Манифест](https://adavydov.github.io/right-to-decide/manifesto/) · [Инструкции агентам](AGENTS.md)

## Конституция и действующий план

[CONSTITUTION.md 1.0](CONSTITUTION.md) — единый содержательный источник, принятый инициатором 6 сентября 2026 года. Полученный Word — исходная читательская копия; принятие всеми соавторами и параметры реального пилота не объявлены согласованными.

Главный вопрос: **как спроектировать развитие человека, когда оно перестаёт быть необходимым условием получения технического результата?** Ответ — «образование, которого нет»: развитие встроено в деятельность, которую люди способны осваивать, продолжать и менять рядом с более сильным интеллектом. Работающая система, развитие участников и самостоятельное продолжение проверяются раздельно.

[Содержание 5.0](manuscript/2026-09-05-rebuild/contents-v5.0.md) следует §7: пролог, шесть частей, восемнадцать глав и эпилог. [Рабочий пакет](manuscript/2026-09-05-rebuild/README.md) разрешает версии. [Аудит согласования](docs/editorial/CONSTITUTION-ALIGNMENT-2026-09-06.md) описывает совпадения, изменения и ограничения проверки существующих глав.

## Редакционный процесс

Начать с конституции целиком и [AGENTS.md](AGENTS.md), затем открыть [действующие правила](docs/editorial/README.md). Принципы 2.0, стиль 4.0, процесс 2.0 и отдельные контракты ролей и приёмки заменяют прежний литературный режим.

Восемь слоёв — философский, космический, исторический, образовательный, предпринимательский, общественный, личный и Омега — имеют [собственные репозитории материалов](docs/editorial/LAYER-REPOSITORIES-01-v1.0.md). Космическое предприятие даёт сквозной модельный сюжет; герои и сцены имеют самостоятельное движение. История, аргументация и художественная линия не подменяют друг друга.

Перед новой главой: конституция, пролог, материалы ведущих слоёв и книжная память → задание по приложению А и Pyramid → композиция → текст → проверка источников и сильного возражения → ритм и холодное чтение → приёмка. У каждого значимого проверяемого утверждения есть источник, точный фрагмент и границы вывода. Все применимые критерии получают минимум 3 из 4; усреднение не скрывает слабое основание. Книга отдельно проверяется как аргумент без сюжета и как сюжет без объяснений.

Старые каноны и выпуски сохраняются как история. Обновление правил не означает, что существующие главы уже переписаны или заново приняты. Оригиналы и частные карточки общей book-memory и восьми репозиториев не публикуются. Операционные обязательства остаются только в Jira.

## Текст, исходники и структура проекта

Содержательный источник — CONSTITUTION.md; план — manuscript/2026-09-05-rebuild/contents-v5.0.md. Пролог и существующие главы сохраняют свои версии. src/data/book.json содержит текущую веб-проекцию. scripts/publish-author-contents.py воспроизводит исторический выпуск 4.0 и не должен запускаться поверх текущих глав; scripts/publish-manuscript.py собирает явно выбранные литературные главы и проверяет действующий выпуск. src/data/previous-edition.json сохраняет прежний корпус для /archive/; повторный DOCX-импорт не является способом обновления текущего выпуска.

Текущая обложка — public/images/book-cover-contents-v4.png, скачиваемое содержание — public/book/contents-v5.0.md. Авторские Markdown и манифесты сохраняются в Git; оригиналы книг, личные карточки и материалы book-memory/ остаются локальными.

## Локальная разработка и обновление сайта

Рабочий Git-корень — отдельный репозиторий **`right-to-decide`**. В исходной папке «Ньютон книги» он находится в `right-to-decide-site/`; родительский `edu40-monograph` обслуживает книгу «Инженерное образование 4.0». Все команды ниже выполняются из корня `right-to-decide`.

Требуется Node.js 24+. Импорт рукописи использует Python 3 и стандартную библиотеку.

```powershell
npm ci
npm run dev
```

Полная проверка в режиме GitHub Pages:

```powershell
$env:NEXT_PUBLIC_BASE_PATH = '/right-to-decide'
npm run check
```

Команда выполняет lint, TypeScript, проверку контента, сборку и проверку статического экспорта. Для изменений только редакционной документации достаточно проверить ссылки, точность переноса и Git diff; литературная приёмка главы проводится отдельно.

Проверка исходников: `python scripts/publish-manuscript.py --check`. Исторический DOCX-импорт описан в [book-import.md](docs/research/book-import.md); его нельзя запускать поверх текущей Markdown-редакции без отдельной миграции.

Сайт включает отдельный /manifesto/, /contents/, /read/prologue/, /read/contents/, /archive/ и страницы авторов, библиотеки и вики. Старый /read/preface/ ведёт к прологу. Плановые главы не имеют ссылки чтения; доступность определяется фактическим составом выпуска.

Push в `main` запускает существующий [GitHub Actions workflow](.github/workflows/deploy-pages.yml): проверку и публикацию статического сайта. Документы в `docs/` сами по себе не добавляют главы в читалку.

Визуальная основа сайта: тёплый светлый фон, тёмная плавающая навигация, крупная гротескная типографика и просторные медиа-модули; референс — brand.ai. Спецификации находятся в `docs/research/`, снимки — в `docs/design-references/`. Используются собственный бренд и авторские изображения; системный гротеск заменяет лицензируемый ABC Monument Grotesk. Атрибуция фотографий: [authors-2026-09-05.md](docs/research/authors-2026-09-05.md).
