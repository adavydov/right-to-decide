# Проверка дополнения MERIT-01 1.0

6 сентября 2026 года. Результат редакционной проверки правил, не приёмка рукописи.

Основание — [решение автора](AUTHOR-DECISION-2026-09-06-MERIT.md). Проверен [MERIT-01 1.0](MERIT-01-v1.0.md). Дополнение зарегистрировано в [действующем каноне](README.md).

## Независимое содержательное чтение

Отдельный агент в роли содержательного оппонента merit_policy_review полностью прочитал два новых документа: решение автора и MERIT-01. Базовые документы и рукопись он полностью не читал; проверку подключений выполнял интегратор. Вердикт: содержательная проверка пройдена, обязательных исправлений нет.

| Проверочный случай | Результат |
|---|---|
| Бесплатный доступ только из достоинства | Необоснованный переход, возврат фрагмента. |
| Разная оплата по результату | Допустима при ясном основании и соблюдении договора. |
| Дивиденды без текущего труда | Допустимы; доход от собственности имеет отдельное основание. |
| Добровольный грант | Допустим без встречного рыночного результата. |
| Спонсор прекратил финансирование | Может отказаться от новых обязательств; существующие должен исполнить. |
| Неудобный эмпирический факт | Сохраняется; ценностная установка его не опровергает. |
| Гражданское участие и корпоративная власть | Разведены; полномочия в компании требуют своего основания. |
| Все богатые заслужили богатство | Вывод из дохода недостаточен; нужно исследовать происхождение. |
| Неэкономическая глава | Допустима неприменимость и отсутствие дополнительных вставок. |

Оппонент подтвердил: сильная добровольная или рыночная альтернатива может проиграть; возражения других сторон сохраняются; новая установка не вводит шаблона прозы или дополнительной шкалы приёмки.

Единственное необязательное уточнение принято интегратором: в предложенном фрагменте пролога перед перечислением оснований вознаграждения добавлено «например». Перечень не выглядит исчерпывающим; правило о доходе от собственности сохранено. Повторной полной проверки из-за этой локальной правки не требовалось. Пример не перенесён в рукопись.

## Подключения и техническая проверка

Подключено 16 действующих входов: корневой AGENTS, AGENTS сайта, реестр, литературная политика, принципы, роли, экономика, приёмка, маршрут, контракт слоёв, исследователь главы, общий контракт частных слоёв и кураторы С01/С05/С06/С09. Остальные кураторы наследуют правило из общего контракта и реестра.

Базовые номера версий сохранены; подключение прямо обозначено как «база плюс MERIT-01 1.0». Все прежние состояния 16 файлов сохранены побайтово в частном архиве book-memory/policy-revisions/2026-09-06-before-merit вне Git сайта; SHA-256 архивов совпадает с исходным.

Проверено 42 относительных ссылок на новое решение, дополнение и их документальные входы: отсутствующих целей нет. SHA-256 всех 450 защищённых файлов совпал с исходным: это 448 Markdown-файлов рукописи, CONSTITUTION.md и src/data/book.json. Полная сборка сайта не запускалась ради документальной правки.

В частном архиве сохранены before.json, protected-before.json и validation.json с перечнями и результатом сравнения. Эта запись подтверждает подключение правил и проверку определённых файлов; она не означает проверки всей рукописи на новую установку, обновления источников, внешней экспертизы, публикации или запуска пилота.
