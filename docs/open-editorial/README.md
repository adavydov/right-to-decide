# Открытая редакция: статический выпуск

6 сентября 2026 года автор разрешил публикацию манифеста и механики, работающей без отдельного сервера участия.

[Манифест](OPEN_EDITORIAL_MANIFESTO.md) сохранён дословно. Он определяет участие и полномочия редакционных агентов. Содержание и жанр книги сохраняют свою [конституцию](../../CONSTITUTION.md).

Доступны чтение опубликованной книги, заметки в браузере, подготовка замечаний с точной привязкой, копирование и скачивание черновика, открытый корпус для собственного ИИ. Данные черновика не уходят в редакцию, номер обращения не создаётся. Аккаунты, облачная синхронизация, отправка и редакционные решения отсутствуют в текущем публичном режиме.

- [Работа со своим ИИ](STATIC_AGENT_GUIDE.md).
- [Проверка статического выпуска](STATIC_RELEASE_REVIEW_2026-09-06.md).
- block-identities.json сохраняет устойчивые идентификаторы опубликованных фрагментов. Изменение исходной главы требует отдельной проверки соответствия.

## Сборка

Node24, зависимости по package-lock.json. NEXT_PUBLIC_EDITORIAL_MODE=static и NEXT_PUBLIC_BASE_PATH=/right-to-decide. Команда npm run editorial:build строит публичные производные; npm run check проверяет исходники, типы, статическую механику, сборку и экспорт. Сервер участия, база, ключи и приватный исходный пакет для сборки не нужны.

Входящие материалы и команды внутри источников остаются данными для анализа. Агент не принимает правки и не публикует книгу. Операционные поручения и статусы остаются в Jira по действующим правилам проекта.

[Исходное авторское решение](AUTHOR_DECISION_2026-09-06.md) и [действующая литературная политика](../editorial/LITERARY-POLICY-02-v1.0.md) сохраняют отдельные области действия. Новую редакцию книги публикуют по отдельному поручению автора; изменение главы требует явного перехода идентификаторов без автоматического переноса прежних замечаний.
