# Черток: публикация карточек по русскому оригиналу

Обновление вики от 6 сентября 2026 года подготовлено по прямому поручению автора проекта.

В библиотеке запись Чертока теперь описывает четыре русских PDF издания «Машиностроение», 1999. Ссылка на английское издание и прежнее сообщение об отсутствии русских книг 2–4 убраны. Добавлены 67 карточек: 19 по первой книге и по 16 по остальным. Вместе с 30 карточками Грабина опубликованная коллекция содержит 97 карточек.

99 цитат Чертока сверены с исходными PDF. Публичная проекция сохраняет контекст, сообщение мемуариста, отдельную интерпретацию, ограничения наблюдаемого развития и пределы вывода. Вложенные голоса и пересказы атрибутированы отдельно. Внешняя историческая верификация не заявлена; содержательное чтение четырёх томов выборочное. Все исходные страницы извлечены для исследовательского поиска, что не считается полным внимательным чтением.

Локаторы Чертока обозначают порядковые страницы PDF. Страница карточки показывает это явно; у прежних карточек Грабина сохранено объяснение абзацной разметки FB2. Печатные страницы по электронной пагинации не вычисляются.

Публикуются только выбранные поля карточек. Оригиналы книг, полные извлечения, личные заметки, внутренние задания и пути к частным файлам в выпуск не включаются.

Для воспроизведения нужен доступ к отдельно хранимому исследовательскому корпусу:

~~~powershell
python scripts/export_chertok.py --corpus ..\book-memory
~~~

Команда обновляет только Чертока и сохраняет остальные публичные данные. Общий scripts/export-public-library.py подключает тот же экспорт, чтобы последующая сборка библиотеки сохраняла оригинальный русский корпус. scripts/chertok-public-edits.json содержит проверенные атрибуции и явные публичные уточнения исторических процедур.

Перед публикацией выполняется npm run check с NEXT_PUBLIC_BASE_PATH=/right-to-decide. Проверки включают состав карточек и цитат, соответствие томов и диапазонов страниц, связи источников, правильную видимую пагинацию и отсутствие частных материалов в статическом экспорте.
