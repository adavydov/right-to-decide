# Предисловие v8.0 — авторская публикация

Дата: 5 сентября 2026 года. Основание: прямое поручение автора «сохрани его и опубликуй» и полный текст в сообщении.

Источник: [preface-v8.0.md](../../manuscript/2026-09-05-rebuild/preface-v8.0.md). Эта версия заменяет предисловие на сайте. Предыдущие локальные версии сохранены.

Роль исполнителя: интегратор и выпускающий. Разрешённый объём: сохранить и опубликовать предоставленный текст. Слова, пунктуация, абзацы и пять разделителей ⸻ сохранены. Заголовок оформлен Markdown-заголовком; конечные пробелы абзацев не переносятся в верстку. Стилевые и содержательные правки не выполнялись. STYLE-01 2.0 прочитан; прямое поручение на публикацию именно авторского текста имеет приоритет над редакционными предложениями. Публикация не является новым научным или стилевым отзывом; исторические утверждения в рамках этого переноса не проверялись заново.

Веб-проекция: раздел preface в src/data/book.json, версия 8.0; SHA-256 источника хранится в chapter.source. Остальная рукопись сохраняет редакцию DOCX от 04.09.2026. Счётчики веб-текста пересчитаны; сведения об исходном DOCX сохранены. Идентификатор редакции в читалке учитывает источник конкретной главы.

Повторный импорт DOCX автоматически применяет scripts/author_preface.py. Отдельное восстановление проекции: python scripts/author_preface.py. Проверка совпадения: python scripts/author_preface.py --check. Проверка всех абзацев экспорта: python scripts/author_preface.py --check --html out/read/preface/index.html.

Технический выпуск: NEXT_PUBLIC_BASE_PATH=/right-to-decide npm run check, затем отправка изменений в main и успешная публикация GitHub Pages. Проверка публичной страницы: python scripts/author_preface.py --check --url https://adavydov.github.io/right-to-decide/read/preface/.

Публичный адрес: [читать предисловие](https://adavydov.github.io/right-to-decide/read/preface/).
