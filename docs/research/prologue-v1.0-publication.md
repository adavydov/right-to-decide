# Пролог v1.0 — авторская публикация

5 сентября 2026 года. Автор переименовал предисловие в пролог, передал новую полную редакцию и поручил сохранить и опубликовать её без ссылок на источники.

Сохранённый файл: manuscript/2026-09-05-rebuild/prologue-v1.0.md. В нём 61 текстовый абзац и четыре разделителя ⸻. Слова, пунктуация и порядок сохранены; заголовок оформлен как Markdown-заголовок, конечные пробелы абзацев удалены. В основной текст не добавлены ссылки, примечания или редакционные комментарии. Предисловие v8.0 сохранено как предыдущая версия.

Роль исполнителя — интегратор и выпускающий. STYLE-01 2.0 прочитан; прямое поручение на сохранение именно авторского текста определяет объём этой работы. Литературная переработка и новый исторический фактчек в поручение не входили.

Независимая сверка файла с сообщением автора завершена: расхождений после указанной технической нормализации нет.

Сборка главы: build_author_prologue() в scripts/author_prologue.py. Публичный заголовок — «Пролог»; основной адрес — /read/prologue/. Старый адрес /read/preface/ сохраняет переход к новому разделу. История предисловия находится в архиве.

Проверка проекции: python scripts/author_prologue.py --check.
Проверка текста, заголовка и отсутствия ссылок/примечаний в экспорте: python scripts/author_prologue.py --check --html out/read/prologue/index.html.
Проверка опубликованного пролога независимо от параллельных локальных правок: python scripts/author_prologue.py --url https://adavydov.github.io/right-to-decide/read/prologue/.

Публикация согласована с параллельной задачей обновления оглавления: один интегратор собирает и отправляет согласованный комплект на GitHub Pages.
