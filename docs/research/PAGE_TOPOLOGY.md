# Page topology

`SiteHeader → HeroSection → ProblemSection → ThesisSection → FrameworkSection → ContentsSection → WorldSection → NoveltySection → AuthorSection → SiteFooter`

## Routes

- `/` — единая русскоязычная страница-проспект будущей монографии.
- Все внутренние переходы — якоря на той же странице.
- Внешние источники и профили открываются в новой вкладке с `rel="noreferrer"`.

## Sections

1. **Header:** бренд «Право на решение», три главных якоря, квадратное раскрывающееся меню остальных разделов.
2. **Hero:** типографическая обложка, дословный заголовок и подзаголовок, governing answer, CTA к тезисам и оглавлению.
3. **Problem:** две разрушенные лестницы; затем четыре ставки для ректора, корпорации, государства и студента.
4. **Theses:** 14 тезисов в четырёх смысловых группах, нумерация 01–14.
5. **Framework:** пятиступенчатая формула права, границы полномочий, три системные метрики.
6. **Contents:** шесть раскрывающихся частей примерного содержания.
7. **World:** шесть международных механик; в каждой — что уже работает и чего она не решает.
8. **Novelty:** восемь заявок на научную новизну + список элементов, которые новизной сами по себе не являются.
9. **Author:** портрет, биография, исследовательская траектория, награды, профили и selected works.
10. **Footer:** статус «книга в работе», автор, контакт, GitHub.

## Interaction model

- Header dropdown: click + outside click + Escape.
- Contents: native `<details>`; один раскрытый раздел не обязан закрывать другой.
- Anchor navigation: smooth scroll; отключается при reduced motion.
- Cards: hover only; никаких каруселей, autoplay или scroll gimmicks.
- Header остаётся в обычном потоке, как у референса.
