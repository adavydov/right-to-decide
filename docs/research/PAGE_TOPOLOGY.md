# Топология

Адаптация: навигация; hero книги; медиа с обложкой; основной вопрос; три связанные проблемы; аудитории (click-driven); вход в содержание; авторы; footer.
Отдельные страницы: содержание с поиском; полный текст с боковым оглавлением и предыдущим/следующим разделом; биографии.
