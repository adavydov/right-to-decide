# ChapterView / ReaderShell
Standalone readable article; server rendered full current chapter from book JSON. Client receives small chapter navigation list, no full book content. Warm paper #f7f5f2, ink#1b1b1b, main text Georgia20px/35px; title44px/48px Arial; nav13px/18px. Desktop sidebar250px and reading column740px, gap60px; sidebar sticky top115px with viewport scroll. Mobile <=900 sidebar becomes collapsible native details, article width100%, default collapsed. Font buttons18/20/22px via CSS custom property, local preference retained. Save valid chapter id/name in localStorage only for user's own local resume, try/catch storage failures. Prev/next links skip planned sections. Keyboard accessible. Article retains paragraphs/headings/tables/figures/quotes/list markers, no raw HTML; table overflow horizontal. Draft edition clearly labeled.
