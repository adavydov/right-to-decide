# Право на решение
Сайт монографии А. М. Давыдова, А. А. Давыдова и Е. А. Давыдова.
[Открыть сайт](https://adavydov.github.io/right-to-decide/)

## Структура
- Главная — вопрос книги, обложка, основные идеи и аудитории.
- /contents/ — содержание с поиском по главам, частям и подзаголовкам.
- /read/ — вход в чтение, продолжение последнего открытого раздела.
- /read/[chapter]/ — весь доступный текст, таблицы, рисунки; размер шрифта и навигация.
- /authors/ — три биографии, проверенные публичные профили и атрибуция фотографий.

Текущая рабочая редакция от 04.09.2026: 18 глав, 10 приложений, вступительные разделы, заключение и библиография. Формулы представлены линейно. Для Егора Давыдова до получения подтверждённого портрета используется монограмма.

## Разработка
Node.js 24+. Выполнить npm ci, затем npm run dev.
Полная проверка: npm run check. Для GitHub Pages установить NEXT_PUBLIC_BASE_PATH=/right-to-decide при сборке.
Развёртывание: существующий GitHub Actions workflow при push в main.

## Обновление текста
Полный воспроизводимый импорт:
python scripts/import-manuscript.py <путь-к-DOCX>
Проверка без записи:
python scripts/import-manuscript.py <путь-к-DOCX> --check

Контракт и точный синтаксис см. docs/research/book-import.md и python scripts/import-manuscript.py --help.
Данные в src/data/book.json. Для раздела без текста предусмотрен status planned; ссылка на чтение появляется только при available. publicationStatus различает draft и published. При обновлении редакции обновить отображаемую дату в интерфейсе и sitemap.
Авторы: src/data/authors.json. Обложка: public/images/book-cover.png. Атрибуция фотографий: docs/research/authors-2026-09-05.md.

## Визуальный референс
brand.ai: тёплый светлый фон, тёмная плавающая навигация, крупная гротескная типографика, просторные медиа-модули. Используются собственный бренд, текст и авторские изображения. Системный гротеск заменяет лицензируемый ABC Monument Grotesk. Извлечённые параметры и спецификации: docs/research/; снимки: docs/design-references/.

Код и авторские материалы имеют разные условия использования — см. LICENSE. Открытая контент-лицензия на текст монографии не предоставлена.
