# Право на решение

Публичный проспект будущей монографии Алексея Михайловича Давыдова
«Инженерное образование как система когнитивного допуска в эпоху
искусственного интеллекта».

**Главный тезис:** ИИ не отменяет необходимость инженера. Он отменяет право
доверять инженеру только потому, что тот выдал правильный ответ.

Сайт: <https://adavydov.github.io/right-to-decide/>

## Что находится на странице

- постановка проблемы двойного разрыва: лестницы взросления и лестницы доверия;
- 14 тезисов будущей монографии;
- итоговая формула и модель права на решение;
- примерное содержание: 6 частей и 18 глав;
- обзор мировых практик с границами доказательств;
- заявка на научную новизну;
- подробная информация об авторе и источники.

## Локальная разработка

Требуется Node.js 24 или новее.

```bash
npm ci
npm run dev
```

Полная проверка статической публикации:

```bash
npm run check
```

GitHub Pages собирает статический экспорт Next.js через workflow в
`.github/workflows/deploy-pages.yml`.
