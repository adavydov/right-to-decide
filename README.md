## Актуальный выпуск 10.1

Пролог, 26 глав, включая 11A и 11B, и эпилог. Раздел «Суть» проводит через все 28 разделов книги и её развязку: 6898 слов, ориентир 30–40 минут. Библиотека содержит читательские карточки источников с тезисами, применением, локаторами и проверенными короткими цитатами там, где они подготовлены.

На сайте доступна только актуальная редакция. Исторические источники и свидетельства остаются в Git и локальной редакции, прежние публичные маршруты и скачивания сняты. Оригиналы книг и частные исследовательские материалы не входят в репозиторий сайта.

Текущая веб-проекция — `src/data/book.json`; точные принятые источники и компактные свидетельства — `manuscript/v10-1/`. Контракт редакции: [EDITORIAL_CONTRACT.md](docs/editorial/v10/EDITORIAL_CONTRACT.md). Полная рабочая конституция находится в локальном комплекте `../book-v10`; установленная копия — `manuscript/v10-1/evidence/CONSTITUTION.md`.

## Разработка и проверка

Node.js 24+, Python 3 и зависимости из `requirements-release-check.txt`.

```powershell
npm ci
$env:NEXT_PUBLIC_BASE_PATH = '/right-to-decide'
$env:NEXT_PUBLIC_EDITORIAL_MODE = 'static'
npm run check
```

Проверка охватывает генератор выпуска, точную проекцию источников, документы, интерфейсные типы, статическую открытую редакцию, сборку, ссылки и публичные границы данных. Подготовка и установка выпуска: [RELEASE_V10_1.md](scripts/RELEASE_V10_1.md). Генераторы прежних версий остаются историческими инструментами; запускать их поверх текущей проекции нельзя.

Push в `main` запускает [проверку и GitHub Pages](.github/workflows/deploy-pages.yml). Содержательное чтение и техническая проверка имеют отдельные свидетельства; агентная редакционная приёмка не называется внешней человеческой экспертизой.

## Сайт и материалы

Главная, «Суть», чтение, содержание, библиотека с карточками, авторы, манифест и пять воспроизводимых модельных досье. Новый визуальный рисунок использует просторную светлую композицию авторского референса и новые сгенерированные иллюстрацию и обложку. Частный HTML референса не публикуется.

Открытая редакция работает статически: заметки на устройстве и скачивание черновика замечаний. Аккаунты, приём материалов и платежи не включены. Исторические заметки читателя не переносятся на другой текст автоматически. [Правила открытой редакции](docs/open-editorial/README.md).

У кода и авторского содержания разные условия использования: [LICENSE](LICENSE). Открытая контент-лицензия на полный текст книги не предоставлена. Сторонние источники сохраняют атрибуцию и свои условия доступа.
